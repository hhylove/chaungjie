# 项目全流程管理

独立入口：创业者发展中心 → 项目全流程管理。独立本地存储 chuangjie-projects-v1；首次打开复制已有创业者模块中的项目记录，原记录保留，不再互相写入。

建立项目：负责人、店铺/营业执照至少一项、三个阶段各自的预算、目标、截止时间。总监提交，总经理通过后进入管理中；驳回可修改重提。页面的模拟处理角色用于演示两种处理权限。

总监按月更新当月新增预算使用金额、三个阶段目标达成率和项目评估。同月修改保留旧版本，统计不重复累计。项目卡显示累计支出、余额、阶段进度、逾期和未更新提示，可搜索并按截至月份查询。详情保留月度记录和审批操作历史。

本模块不依赖人事入职、创业者协议或资产发放手续，不修改创业者人员的测试/正式状态，不设置额外分阶段拨款审批。

验证：node --test projects/engine.test.js。浏览器已验证独立建立、总经理审核、月报保存及刷新后数据保留。演示数据保存在当前浏览器，不代表生产权限或跨设备服务。
