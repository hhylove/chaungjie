# 员工智能助理 B 阶段部署顺序

1. 备份 MySQL。确认已执行 A 阶段迁移，再执行 `sql/mysql/assistant-stage-b-20260926.sql`。B 迁移新增配置列、独立知识库表、来源关联表和菜单；不要重复执行其中的 `ALTER TABLE`。
2. 部署后端与前端，重启正在运行的 `ChuangjieServerApplication`。检查「智能助理管理 → 独立知识库」菜单；新租户套餐需纳入新增菜单 ID。
3. 配置并测试内网向量模型，确认其 `/embeddings` 与现有回答模型的 `/chat/completions` 均可访问。
4. 新建限制可见的测试知识库，分别授权员工、部门和角色，上传 TXT、PDF、DOCX 测试文档。用已开通员工账号提问，核对来源名称和版本。
5. 撤销授权、停用文档、停用角色，分别验证新提问及历史会话不会再返回受限知识答案。用另一租户复测隔离。

接口字段见 [B 阶段接口文档](CHUANGJIE-ASSISTANT-STAGE-B-API.md)。数据库迁移和真实内网向量服务未在开发环境执行，运行验收仍需在目标环境完成。当前不提供 OCR、外部业务数据查询或超出 5000 个授权片段的大规模向量索引。
